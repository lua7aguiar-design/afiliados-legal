Ferramenta pessoal · single-tenant

Plataforma de Automação para Afiliados

Ferramenta pessoal que conecta uma conta de afiliado Shopee a uma conta TikTok para gerar e publicar vídeos curtos de divulgação de produtos, sempre com aprovação manual do operador antes de qualquer publicação.

Como funciona

  • Produtos de afiliado Shopee são cadastrados no painel do operador;
  • Um vídeo curto é gerado localmente (narração + imagem do produto + legenda com disclosure de publicidade);
  • O vídeo fica em fila de aprovação — só é publicado no TikTok depois de uma revisão manual feita pelo próprio operador;
  • A publicação usa a TikTok Content Posting API, em nome da conta TikTok conectada via OAuth pelo operador.
