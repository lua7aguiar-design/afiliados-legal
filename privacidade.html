Política de Privacidade

Plataforma de Automação para Afiliados — atualizado em 30 set 2026

Esta Plataforma é uma ferramenta interna de automação de marketing de afiliados, usada apenas pelos seus dois operadores para divulgar produtos nas próprias contas. Não é oferecida ao público e não tem cadastro aberto. Esta política descreve quais dados são tratados quando uma conta do Facebook (Página), do Instagram, do Pinterest ou um canal do Telegram é conectado à Plataforma.

01Dados coletados

PermissãoDadoUso
Facebook — pages_show_list, business_management Lista das Páginas que a conta administra, com nome e ID de cada uma Escolher qual Página conectar. business_management é necessário porque as Páginas foram criadas dentro de um Portfólio Empresarial da Meta; nenhum outro dado do portfólio é lido ou alterado
Facebook — pages_manage_posts Nenhum dado de terceiros é lido Criar, agendar, editar e apagar posts (foto + legenda) na Página conectada, sempre a partir de uma publicação aprovada manualmente
Facebook — pages_read_engagement Link público e texto dos posts criados pela própria Plataforma Guardar o link de cada post publicado e conferir se uma edição foi aplicada
Instagram — instagram_business_basic Nome de usuário e ID da conta profissional do Instagram conectada Exibir no painel qual conta está conectada
Instagram — instagram_business_content_publish Link público dos posts criados pela própria Plataforma Publicar posts (foto(s) + legenda) na conta conectada, a partir de uma publicação aprovada manualmente
Pinterest — boards:read, boards:write, pins:read, pins:write Lista de boards da conta, com nome e ID Escolher o board e criar pins (imagem + título + descrição + link) nele, a partir de uma publicação aprovada manualmente. boards:write é exigido pela Pinterest para criar pins dentro de um board
Telegram — Bot API Nome e ID do canal conectado Publicar posts (foto(s) + legenda) no canal, a partir de uma publicação aprovada manualmente. O token do bot é criado e informado manualmente pelos operadores (@BotFather), sem fluxo OAuth
— Tokens de acesso e de renovação (ou o token do bot, no Telegram) e a data de validade de cada um Guardados criptografados e usados só para autenticar as ações acima. Tokens com validade (Instagram e Pinterest) são renovados automaticamente antes de vencer
Shopee — API de afiliados Produtos do programa de afiliados e relatório de conversões (ID do pedido, itens, status e comissão). Nenhum dado pessoal de comprador é recebido ou guardado Escolher produtos para divulgar, gerar links de afiliado e acompanhar as comissões
Operadores Nome, e-mail e senha (guardada só como hash) dos dois operadores Login no painel da Plataforma

A Plataforma não lê perfis, seguidores, mensagens, comentários ou qualquer dado de outras pessoas nas redes conectadas.

02Como os dados são usados

Os dados acima são usados exclusivamente para publicar posts de divulgação de produtos de afiliados nas contas dos próprios operadores. Toda publicação passa por aprovação manual no painel; depois de aprovada, ela é publicada automaticamente no horário agendado. Um post ainda agendado pode ser ajustado ou apagado automaticamente pela Plataforma (por exemplo, quando o produto sai do ar na Shopee ou para atualizar o link de afiliado). Não usamos os dados para anúncios, perfilamento, revenda ou qualquer outra finalidade.

03Compartilhamento com terceiros

Não compartilhamos, vendemos ou cedemos dados a terceiros. Os dados trafegam apenas entre a Plataforma, as APIs oficiais do Facebook, do Instagram, do Pinterest, do Telegram e da Shopee, e os provedores de infraestrutura descritos abaixo, estritamente para executar as ações pedidas pelos operadores.

04Armazenamento e segurança

A Plataforma roda nos computadores dos operadores (via Docker) e guarda seus dados num banco PostgreSQL gerenciado pelo Supabase, com acesso restrito por senha. Tokens de acesso são guardados criptografados. O painel exige login, e a comunicação com a Plataforma é feita só por HTTPS.

As fotos dos produtos divulgados e a página pública de links dos produtos ficam hospedadas no GitHub Pages. Essa hospedagem contém apenas fotos e links de produtos, nenhum dado pessoal.

05Retenção e exclusão de dados

Os tokens ficam guardados enquanto a conta estiver conectada. Desconectar a integração no painel da Plataforma apaga os tokens guardados. Para revogar o acesso também na própria rede, use as configurações de apps conectados do Facebook, do Instagram ou do Pinterest (no Telegram, remova o bot do canal).

Para pedir a exclusão completa de qualquer dado retido (tokens, nome e ID da Página, conta, board ou canal, e o histórico de posts publicados), envie um e-mail para o contato no fim desta página. A exclusão é feita em até 7 dias.
