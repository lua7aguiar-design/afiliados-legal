Política de Privacidade

Plataforma de Automação para Afiliados — atualizado em 1 set 2026

Esta Plataforma é uma ferramenta pessoal de automação de marketing de afiliados, operada por um único usuário (single-tenant). Esta política descreve quais dados são tratados quando você conecta sua conta do Facebook (Página), Instagram, Pinterest ou um canal do Telegram.

01Dados coletados

EscopoDadoUso
pages_show_list, pages_read_engagement Lista de Páginas administradas, nome da Página Exibir no painel qual Página está vinculada
pages_manage_posts Nenhum dado é lido Publicar posts (foto + legenda) em nome da Página, após aprovação manual
instagram_basic Nome de usuário e ID da conta comercial do Instagram vinculada à Página Exibir no painel qual conta do Instagram está vinculada
instagram_content_publish Nenhum dado é lido Publicar posts (foto + legenda) na conta do Instagram vinculada, após aprovação manual
Pinterest — boards:read, pins:write Lista de boards, nome do board Publicar pins (imagem + legenda) no board conectado, após aprovação manual
Telegram Bot API Nome/id do canal conectado Publicar posts (foto(s) + legenda) no canal, após aprovação manual — o token do bot é gerado e colado manualmente pelo operador (@BotFather), sem fluxo OAuth
— Access / refresh token (ou token do bot, no caso do Telegram) Armazenados criptografados, usados só para autenticar as publicações

02Como os dados são usados

Os dados acima são usados exclusivamente para permitir a publicação de posts (foto + legenda) de divulgação de produtos de afiliados nas contas conectadas do próprio operador. Não usamos os dados para anúncios, perfilamento, revenda ou qualquer finalidade além da operação da própria Plataforma.

03Compartilhamento com terceiros

Não compartilhamos, vendemos ou cedemos dados a terceiros. Os dados trafegam apenas entre a Plataforma e as APIs oficiais do Facebook, do Instagram, do Pinterest, do Telegram e da Shopee, estritamente para executar as ações solicitadas pelo operador (publicar post, ler produtos de afiliado).

04Armazenamento e segurança

Tokens de acesso são armazenados criptografados. A Plataforma roda localmente (infraestrutura própria do operador via Docker), sem exposição de banco de dados a redes públicas.

05Retenção e exclusão de dados

Você pode revogar o acesso da Plataforma à sua conta do Facebook, Instagram, Pinterest ou ao canal do Telegram a qualquer momento nas configurações de apps conectados de cada rede (no Telegram, removendo o bot como admin do canal), ou desconectando a integração dentro do painel da Plataforma — isso invalida e remove os tokens armazenados. Para solicitar a exclusão completa de qualquer dado retido (tokens, nome da Página/conta vinculada), envie um e-mail para o contato ao final desta página; a exclusão é feita em até 7 dias.
